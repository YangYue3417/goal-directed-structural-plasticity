# 发现: SNN 梯度 bug + 环境控制/气味导航实验结果

> 2026-08-12 | 分支: neuron-specialization | 本日实验

## 1. 关键 bug 修复: LIF 硬阈值无梯度

**现象**: 旧 gridworld v2 模型是"假导航" — 95% 右转, 到达 0/200;
odor 训练 1000+ episodes 从未找到食物。

**根因**: `SparseLIFLayer` 中 `s_new = (u >= threshold).float()` 是硬阶跃,
梯度处处为 0 → **LIF 层完全学不到**, 只有 action_head 线性层能学。
模型退化为"随机投影 + 可学输出头", 策略坍缩为最低成本动作 (右转)。

**修复** (`model/sparse_snn.py`): SpikeFunction (autograd.Function)
前向硬脉冲 + 反向 fast sigmoid surrogate `1/(1+|10(u-th)|)²`。
验证: 梯度从 0/6 参数 → 6/6 参数流动。

**效果** (重训后):
- gridworld v2: ep 600 奖励 +10.65 (到达目标), ep 1400-1800 稳定 13.05/12步
- odor: ep 600/1400/1800 找到食物 (修复前从未)

**教训**: 类脑脉冲网络的"真实"前向必须配替代梯度, 否则是死的。
这也解释了分支内 STE 讨论的反复 — 硬 mask/硬阈值都是同一个坑。

## 2. 环境控制实验 (Q4: 分化可控吗)

条件: MNIST 0-4 (阶段1) → 5-9 + 回放 (阶段2), 1024 池 top-64。

| 条件 | 回放 | A神经元 | B神经元 | 共享率 | 专精 | 保持A |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| C0 | 无 | 5 | 446 | 0.002 | 0.754 | 0.231 (崩) |
| C1 | 50:50 随机 | 387 | 121 | 0.185 | 0.844 | 0.992 |
| C2a | 70% A | 482 | 74 | 0.097 | 0.940 | 0.992 |
| C2b | 30% A | 217 | 226 | 0.245 | 0.746 | 0.989 |
| C3 | 50:50 难样本 | 221 | 267 | 0.253 | 0.766 | **0.478** |
| C4 | 50:50 课程序 | 336 | 85 | 0.215 | 0.810 | 0.986 |

**P1 (比例→分化方向): ✅ 强成立**
A 神经元占比随回放比例单调: 70%→86%, 50%→76%, 30%→49%。
**环境比例是结构方向的主旋钮。**

**P2 (内容→专精): ❌ 反直觉**
难样本 (阶段1 误分类) 回放 → 专精反而降 (0.766) + 保持率崩 (0.478)。
解释: 难样本是边缘样本, 回放它们把表示拉向边缘分布, 覆盖被破坏。
→ 回放内容集中在困难边缘会伤记忆 (代表性/均匀覆盖更重要)。

**P3 (顺序→层次): ❌ 不成立**
课程式顺序 (前多后少) 共享率 0.215 > 随机 0.185, 无收益。
→ 当前实现下顺序不是有效旋钮。

**结论**: "环境是塑形工具"部分成立 — 比例调方向, 内容/顺序在当前
实现无效。环境控制 = 频率塑形 (统计), 非选择性塑形 (内容) 失败。

## 3. 气味导航 RL (Q5: 分化产生功能吗)

修复梯度 + 奖励塑形后 (6×6 迷宫, 2 食物):

| 指标 | 训练后 (best) | 随机初始 (对照) |
|------|:---:|:---:|
| 觅食率 (食物/回合) | **2.0/2.0** | 0.0 |
| 撞墙 (每回合) | 0.0 | 2.0 |
| 前进比例 | 0.15 | 0.033 |
| 气味利用 | 0.20 | 0.00 |
| 位置选择性神经元 | 0/256 | 6/256 (噪声) |

**行为功能: ✅ 真实且必要** — 训练后觅食满分, 随机对照为零。

**位置细胞: ❌ 未涌现 (气味任务)** — 训练后 0/256, 反而是随机噪声水平。
解释: 气味导航 = 反应式趋性 (taxis), 只需要 smell 梯度跟随,
不需要空间记忆 → 不产生位置细胞。

**gridworld (新模型, 修复后)**: 到达 200/200 (旧假导航 0/200),
位置选择性 24-36/256, 方向细胞 59/256, 位置解码 0.017 (≈随机 0.010)。
→ 导航可真实完成, 但也不依赖强位置细胞 (分布式方向+弱位置编码足够)。

**核心结论 (Q5)**: 分化 (神经元发放模式) 在 RL 具身任务中产生行为功能,
但功能形式是"反应式"的 (趋性/避障), 不需要"记忆型"位置细胞。
位置细胞可能只在需要空间记忆的任务中出现 (如食物消失/多目标规划)。

## 5. 大迷宫空间导航 (Q5 升级: 记忆型分化) — 负结果 ❌

任务: 20×20 迷宫 + 3 食物固定位置 + 固定起点 (0,0), 测最短路径。
BFS 最优 (贪心 TSP): 33 步。256 神经元 LIF SNN + REINFORCE (N=8 并行)。

| 模型 | 测试迷宫 | 食物率 | 路径效率 |
|---|:---:|:---:|:---:|
| untrained | seed42 (易) | 0.283 | 0.006 |
| 固定臂 | seed42 (训练迷宫) | 0.327 | 0.007 |
| 随机臂 | seed42 (未见过) | 0.310 | 0.004 |
| untrained | seed7 (难) | 0.080 | 0.024 |
| 固定臂 | seed7 (新迷宫) | 0.100 | 0.028 |
| untrained | 随机迷宫 | 0.073 | 0.011 |
| 随机臂 | 随机迷宫 (训练分布) | 0.027 | 0.003 |

**结论: 训练没有学会空间导航。**
1. 易迷宫: 训练 (0.327) ≈ 运气 (0.283) — 无增益
2. 新迷宫: 固定臂 (0.100) ≈ untrained (0.080) — 无记忆迁移
3. 随机迷宫: 随机臂 (0.027) < untrained (0.073) — 训练损害觅食
   (学到避免撞墙 → 风险厌恶 → 少移动 → 少碰食物; 奖励结构主导)
4. 路径效率 ~0.005: 从不接近最短路径 (250/33 步)

**解释**: 之前 6×6 气味导航成功 = 反应式趋性 (小规模可学);
大迷宫需要空间记忆/规划 → 超出 256 神经元 LIF + REINFORCE 容量。
位置细胞不涌现 = 网络连基本导航都未学会 (前置条件未满足)。
呼应 FINAL_SUMMARY: "功能需结构偏置" — 空间规划需要记忆结构
(更大网络 / 循环记忆 / 显式地图), 非当前架构所能及。

**修复方向** (若继续): 奖励重塑 (食物正信号加大, 墙惩罚降低),
更大网络 (1024+), 或换 PPO/GAE (REINFORCE 方差太大)。
