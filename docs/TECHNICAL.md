## 1. 核心发现 (数据证据)

### 1.1 预测强迫结构 (表征由任务需求决定)

同样的网络架构, 训练目标决定隐状态表征:

| 训练目标 | 隐状态位置解码 | 结论 |
|:---|:---:|:---|
| 世界模型 (多步预测) | **94.9%** | 预测迫使空间编码 |
| 直接策略 (RL) | 4.2% (≈随机) | 策略可绕开空间 |

机制: 多步预测目标使"空间布局"成为预测的必要信息 → 隐状态被迫编码空间。

### 1.2 环境诱导生长 (功能价值)

误差驱动 (环境反馈) 的生长产生功能关键神经元:

| 实验域 | 指标 | func | rand | 比值 |
|:---|:---|:---:|:---:|:---:|
| 符号 (等容量 248/512) | 删 60 神经元后预测误差上升 | +2312% | +1572% | **1.47×** |
| 视觉 v3 | 存活生长神经元激活率 | 0.380 | 0.268 | **+42%** |

**优胜劣汰**: 生长 + 淘汰 (激活率<0.005 回收槽位) 使存活者激活率 0.20 → 0.38 (接近核心 0.40)。脑容量有限 → 生长必须配淘汰。

### 1.3 认知地图: 指纹 vs 路径积分

| 传感器 | 单帧解码 | 积分后 | 积分增益 | 解读 |
|:---|:---:|:---:|:---:|:---|
| 强 (多距离墙感+大气味) | 0.508 | 0.405 | -0.10 | 指纹已够 |
| 纯墙感 (360 状态 8 组歧义) | 0.722 | **0.967** | +0.24 | 路径积分工作 |
| 视觉 (5×5 视野) | 0.72 | — | — | 视觉指纹 |

**连接掩码学习 → 感受野浮现**: 每神经元连接掩码 (softmax + 熵正则) 收敛到 ~1 格空间位置。熵 0.797 → 0.050, 感受野 25/25 位置覆盖 — 不需要预设感受野, 环境统计塑造连接 (V1 发育的计算版)。

### 1.4 睡眠巩固边界条件

| 发现 | 证据 |
|:---|:---|
| 结构化重放 = 全链信用分配 | 1 次反向扫描 = 8 轮随机 (零误差 vs 6400 次更新) |
| 多日昼夜循环 (静态) | 做梦: 三任务 97/98/90% vs 无梦: 0/0/92% |
| 动态环境片段回放 | 片段+随机方向+无降标 = 30 天存活 |
| **降标依赖容量压力** | 动态下 0.95/夜降标 → 12-14 天死 (权重剩 21%) |

### 1.5 30 昼夜动态生存 + 迁移

校准: 10×10, 6 食物, E0=200, 白天 60 步, 恢复 80, sigma=15 (地图每日变化 + 跨天能量)。

| 验证 | 结果 |
|:---|:---|
| WM+V 生存 | 30 天 (26 食物, 能量 480-660) |
| 稳定性 | seed 43/44/45/7 全部 31 天 |
| 迁移 | 尺寸 8/12, 食物 4/8, 墙密度 0.03/0.08 → 全 31 天 |
| 区分度 | WM+V 30 vs 随机 13 天 |
| 边界 | 能量经济边缘 (3食物/天80步) 4 天 vs 随机 2 天 |

## 2. 方法

### 2.0 统一入口 (迁移正确性保障)

`train_gdsp.py`: 生长/淘汰/睡眠是**必需运行时组件** (自动执行),
迁移新任务只换环境+观测 — 避免手动组装漏组件 (CartPole/Walker 迁移教训)。

```bash
python train_gdsp.py --env cartpole   # 纯框架: 世界模型+生长+淘汰+学习V+MPC
python train_gdsp.py --env walker     # 生长自动接入 (14 个), 探索不足是数据问题
```

### 2.1 世界模型

```
观测 (符号向量 / 图像) → 编码器 (Linear / 空间保留 CNN)
  → 连接掩码池 (SparseUnit / ConnectPool: top-k 稀疏 + 感受野学习)
  → GRU 循环积分 (认知地图载体)
  → latent 预测 (Dreamer 式, 不预测像素) + 奖励预测
```

- latent 目标: 预测下一时刻潜在特征 (z_pool 或 z_cnn), MSE
- 训练: BPTT (T=20-30), 多步预测

### 2.2 生长与淘汰

```
生长 (误差驱动): 位置误差图 → 新神经元 score 尖峰指向高误差位置
                + 权重克隆高负载活跃神经元 + 扰动
淘汰 (用进废退): 激活率 EMA < 0.005 的生长神经元 → 槽位回收
再生长: 复用回收槽位
```

### 2.3 决策 (生存)

- 价值函数 V: 多地图随机策略 MC 回报回归
- 规划: D=3 动作树搜索 (批量 BFS 展开) + V bootstrap
- 4 方向气味感知 (前后左右)

### 2.4 睡眠巩固

- 片段回放: 当天轨迹随机片段 × 随机正/反向 (ripple 真实模式)
- 突触降标: 权重 × scale (静态有效, 动态有害 — 依赖容量压力)

## 3. 实验配置

| 参数 | 值 |
|:---|:---|
| 迷宫 | 10×10 (校准后), 6 食物, 墙密度 0.05 |

## 6. 局限性 (诚实)

1. 全部在玩具环境验证 (10×10 迷宫 / 小 MNIST), 无真实规模实验
2. 关键数字单 seed 为主, 需多 seed 统计检验
3. 视觉生长删除验证噪声级 (解码探针重拟合敏感), 激活率是可靠指标
4. Atari 为机制验证 (随机 50K 帧), 非性能基准
5. "生长=容量" 的翻案仅在预测任务成立, 分类 (记忆) 任务上随机生长仍够
