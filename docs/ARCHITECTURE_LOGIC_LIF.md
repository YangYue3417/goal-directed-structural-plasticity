# 架构: 句压缩记忆 + LIF 逻辑理解

## 设计原则
1. **可解释**: 句向量 / 活跃神经元 / 关系+依据 三层可读
2. **逻辑一致**: LIF 时间积累 (逻辑先后), 非 token 统计
3. **宁缺毋滥**: 低置信 → "不确定" (正确模糊 > 瞎编 token)

## 架构
```
句子序列 S = [s₁...sₙ] → 句编码 (句向量 vᵢ)
  → LIF 逻辑积累 (V_m 积分, τ 分工, 阈值事件)
  → 逻辑头 (关系判断 + 置信度 + 依据)
  → 结构化输出 (蕴含/矛盾/无关/不确定)
```

## 层设计
- ① 句编码: 句子 → vec (语义压缩, 句级记忆, 替代 token KV)
- ② LIF 积累: vᵢ 序列 → 连续电势 (逻辑链), 阈值事件 (逻辑特征)
- ③ 逻辑头: 关系分类 + 置信度 + 支持句 (selective: 低置信拒答)

## 训练目标
- 关系分类 (蕴含/矛盾/无关/不确定) + 推理链
- 不确定类: 训练允许 (冲突/缺失 → 不确定, 不强编)

## 可解释检查点
句向量聚类 / 逻辑神经元映射 / 错误定位 (哪句/哪个神经元)

## 规模
~15-30M 参数 (句编码 10M + LIF 512-1024 + 头), 16GB 可训

## 实现验证路径
符号逻辑 (A→B→C 规则链, 跳跃→不确定) → 小 NLI → 推理链

## 推理有效性证明 (prove_reasoning.py)

序列依赖任务 (中间跳跃 → 不确定, 查表必败):

| 模型 | 确定acc | 不确定acc | 总acc |
|:---|:---:|:---:|:---:|
| 单符号查表 (只看最后) | 0.475 | **0.000** | 0.350 |
| **LIF 序列** | 0.832 | **0.916** | **0.854** |

**证明推理有效**:
- 中间跳跃检测 (跨位置) — 查表不可能 (0.000), LIF 91.6%
- 消融: LIF 2.4× 优于查表
- = LIF 序列积累是真推理 (跨位置逻辑), 非单符号查表

## 通用逻辑验证 (prove_general.py) — 防过拟合: 多规则 + 新规则

训练 16 规则, 测试 8 种未见规则:

| 模型 | 确定 | 跳跃检测 | 总acc |
|:---|:---:|:---:|:---:|
| 单符号查表 | 0.219 | 0.625 | 0.331 |
| **LIF 序列** | 0.838 | 0.917 | **0.860** |

**证明**:
- 新规则 (未见) 下 LIF 0.860 = 规则无关的自洽检测 (通用逻辑)
- 查表记忆训练规则 → 新规则失效 (0.331)
- 非单规则过拟合: 跨规则泛化 + 跨位置 (跳跃 0.917)
= 推理 = 通用逻辑 (规则无关), 三层机制性证明 (消融/跨位置/跨规则)
