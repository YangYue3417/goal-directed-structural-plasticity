# DESIGN: 神经世界模型 — 空间记忆涌现的强迫机制

> 2026-08-12 | 分支: neuron-specialization | 论证文 + 实验设计
> 动机: 直接策略学习在 20×20 迷宫的负结果 → 换机制验证"空间表征何时涌现"

---

## 0. 论证摘要 (TL;DR)

直接策略学习无法回答"神经网络能否涌现空间记忆", 因为**任务不需要它** —
导航可以用反应式趋性完成 (实测: 位置细胞 0/256, 训练≈运气)。
神经世界模型把"预测下一步状态"变成硬目标, **空间布局成为预测的必要信息**,
网络被迫在隐状态中编码空间 — 这是检验空间表征涌现的**最小充分机制**。

---

## 1. 为什么直接策略路线走不通 (负结果回顾)

### 1.1 实测证据 (2026-08-12, 20×20 迷宫)

| 模型 | 食物率 | vs 运气 | 位置细胞 |
|:---:|:---:|:---:|:---:|
| untrained (易迷宫) | 0.283 | 基线 | — |
| 直接策略 (训练迷宫) | 0.327 | ≈运气 | 62/256 (无关) |
| 直接策略 (新迷宫) | 0.100 | ≈运气 | 无迁移 |
| 直接策略 (随机迷宫) | 0.027 | **<运气** | 训练反而损害 |

### 1.2 逻辑诊断: 为什么位置细胞不涌现

```
导航任务可分解: (a) 避障 = 局部反应, (b) 觅食 = 气味趋性, (c) 规划 = 空间记忆
直接策略学到 (a)(b) 就够拿到 90% 的奖励结构 → (c) 无梯度压力 → 不编码空间
= 编码经济原则: 网络只分配神经元给有功能价值的特征
```

**结论**: 直接策略不是"学不会空间", 是"不需要空间"。要让空间表征涌现,
必须让"知道自己在哪/世界长什么样"成为完成任务的**必要条件**。

## 2. 核心论证: 预测 = 空间编码的强迫函数

### 2.1 逻辑链

```
世界模型目标: f(s, a) → (s', r)    [学环境动力学]
要求: 要准确预测 s' = (x', y', 朝向', 气味'), 模型必须知道:
      - 当前在哪 (位置编码)
      - 墙在哪 (布局编码)
      - 动作如何改变位置 (运动学)
→ 空间信息从"可选"变"必需" → 隐状态被迫编码空间
→ 位置细胞式的结构是预测目标的必然产物, 不是巧合
```

### 2.2 文献支撑 (三条独立证据链)

| 证据 | 来源 | 含义 |
|------|------|------|
| **Grid cells in navigation agents** | Banino et al., Nature 2018 (DeepMind) | LSTM 做矢量导航 (必须整合位置) → **网格细胞自发涌现** — 与我们的论证完全同构 |
| **NWM / RAEv2** | RAEv2 arXiv 2605.18324 §4.2 | 导航世界模型预测未来帧 → 多层级聚合保空间结构 → 生成质量大幅提升 (FVD 105 vs 312) |
| **预测编码理论** | 类脑学习综述 (本项目 04) | 大脑皮层 = 预测机器; 空间表征是预测需求的副产品 |

### 2.3 与直接策略的本质差别

| | 直接策略 | 世界模型 |
|:---:|:---:|:---:|
| 学习目标 | 最大化回报 (可绕开空间) | 最小化预测误差 (不可绕开空间) |
| 空间信息角色 | 可选捷径 | **硬需求** |
| 失败模式 | 反应式局部最优 (惰性) | 模型偏差累积 (白日梦) |
| 失败可诊断 | 奖励不变, 原因隐蔽 | 预测误差直接可见, 可逐步归因 |

## 3. 实验设计

### 3.1 任务 (复用 maze_nav 环境, 不改)

20×20 迷宫 + 3 固定食物 + 固定起点。确定性动力学。

### 3.2 模型: SNN 世界模型 (延续类脑主线)

```
输入: obs_t (9维) + action_t (one-hot 3) → SparseSNN (LIF, 256×2)
输出: 预测 obs_{t+1} (9维回归) + 预测 reward (标量)
训练: 监督学习! loss = MSE(obs_next) + MSE(reward)
      (不再是稀疏奖励 RL — 每步都有稠密监督信号, 方差为零)
```

**关键选择**: 用 LIF 而非 RNN — 保持与 neuron-specialization 分支的类脑一致性;
脉冲网络的时序动力学天然适合轨迹预测。LIF 隐状态 = 空间记忆的载体。

### 3.3 决策层 (两种规划, 先简单后复杂)

```
M2 版本: 想象 rollout — 给定 (s, 候选动作序列), 用世界模型展开, 选累计奖励最高的
M3 版本: 隐空间价值 — 世界模型隐状态上训价值头, 贪心选择 (Dreamer-lite)
```

### 3.4 对照矩阵 (可证伪)

| 臂 | 配置 | 检验 |
|:---:|:---:|------|
| W1 | 世界模型 + (x,y) 输入 | 基线: 空间信息可用时能否编码+规划 |
| W2 | **世界模型 - (x,y) 输入** | **核心: 不给位置, 模型被迫自组织空间 (最强证据)** |
| W3 | 随机迷宫 | 泛化: 是否学到通用动力学 vs 背迷宫 |
| D1 | 直接策略 (已有数据) | 跨机制对照: 位置解码应显著低于 W1/W2 |

### 3.5 指标

| 指标 | 定义 | 预期 |
|------|------|------|
| 一步预测准确率 | obs_next 的 (x',y') MAE | W1/W2 收敛 << 随机 |
| **隐状态位置解码** | LIF 隐状态 → 线性探针解 (x,y) | W1/W2 高 (核心证据) |
| 位置选择性神经元 | max>mean×2 (沿用 eval_place_cells2) | W2 > D1 |
| 规划成功率 | 想象 rollout 选的动作 → 真实执行的食物率 | W2 显著 > 运气 |
| 路径效率 | 实际步数 / BFS 最短 | W2 > 0.3 (直接策略 ~0.005) |

## 4. 可证伪预测 (写进论文前的验收标准)

```
P1 (机制): 世界模型隐状态的位置解码显著高于直接策略 (W1 vs D1)
P2 (自组织): 去掉 (x,y) 输入 (W2), 位置解码仍显著 > 随机 → 空间自涌现
P3 (功能): 想象规划的食物率显著高于运气基线 (0.283), 且 > 直接策略 (0.327)
P4 (结构): 位置选择性神经元数 W2 > D1
若 P1-P4 全不成立 → 空间记忆涌现假说被证伪, 记录负结果 (分支一贯做法)
```

---

## 5. 实现路径 (里程碑)

```
M1 [0.5天] 世界模型管线: SparseSNN 改造成预测头 (obs_next + reward 回归)
          验收: 一步预测 MAE 收敛, 训练稳定 (监督学习, 无 RL 方差)
M2 [0.5天] 想象规划: 候选动作序列 rollout → 选最优 (小搜索树, 深度 ≤5)
          验收: 规划食物率 > 运气
M3 [0.5天] 位置解码评估: 隐状态线性探针 + 选择性指标 (复用 eval 工具)
          验收: P1-P2 数字出炉
M4 [0.5天] 对照跑全: W1/W2/W3 + D1 汇总, 写 FINDINGS
```

**总成本 ~2 天, 全部小模型 (256 神经元 SNN, 单卡几分钟/轮)** — 远低于直接策略的
反复调参 (我们已烧了 1 天在 REINFORCE 方差上)。

## 6. 风险与预案

| 风险 | 预案 |
|------|------|
| 模型学成"查表" (确定性世界, 平凡解) | W2 泛化测试: 新迷宫预测误差上升则证明学了布局; 食物消失任务 (记忆必须跨 episode) |
| LIF 预测精度不足 | 换 RNN 基线; 或加大隐状态 (1024) |
| 想象规划视野短 (模型偏差累积) | 短 rollout (≤5 步) + 价值头辅助; 深度优先于宽度 |
| 位置解码指标平凡 (输入里就有 x,y) | W2 (无 x,y 输入) 是反制: 解码高才证明自组织 |
| 监督 loss 被位置项主导 | 各分量加权/归一化 (x,y 在 [0,1] 已归一) |

## 7. 预期贡献 (论文定位)

1. **机制对照**: 同一任务, 直接策略 vs 世界模型 → 空间表征涌现的条件 = 预测目标
   (编码经济原则的经验验证: "表征由任务需求决定")
2. **类脑衔接**: 脉冲网络世界模型的隐状态自发出现位置细胞式结构
   (呼应 Banino 2018 网格细胞, 但用 SNN 而非 LSTM)
3. **与块级 MoE 叙事的连接**: 世界模型迫使的"空间专精" = 神经元级专精的功能例证
   — 回答分支核心问题 "专精何时有功能价值"
