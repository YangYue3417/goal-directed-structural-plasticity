## 五、方法论教训 (沉淀)

1. **稀疏事件必须显式采样** (死亡/食物) — 否则模型学到半个世界
2. **长程信用靠价值函数/重放, 不靠奖励头** — 信号分层
3. **降标依赖容量压力** — 静态饱和时有效, 动态通用时有害
4. **传感器决定指纹 vs 路径积分** — 验证认知必须分离两者
5. **能量经济校准** — 日耗 vs 单食物恢复, 测试可过不可躺赢
6. **规划器工程**: 4方向气味/动作树搜索/V bootstrap/脱困
7. **函数近似干扰** — 逐状态更新扰动全网络, 表格型验证机制更干净

## 八、图像迁移验证 ✅ (2026-08-14)

视觉网格世界: 迷宫渲染成局部第一人称视野 (5×5 格 → 20×20 像素, 含墙/食物/agent 标记)
架构: CNN 编码器 → 潜在特征 z → GRU 积分 → latent 预测 (Dreamer 式, 不预测像素)

结果:
- 世界模型训练收敛 (loss 0.099)
- 固定地图像素→位置解码: **0.722** (随机基线 0.144, 高于随机 +0.58)
- 指纹 vs 积分: 5×5 视野信息丰富 → 单帧指纹够 (0.66-0.72), 积分无增益
  — 与符号实验 strong sensor 结果一致 (故事迁移)

**结论**: 机制 (世界模型/认知地图) 在图像观测下成立; 架构观测无关。
下一步: 更小视野 (3×3, 积分有任务) / 视觉下生长 / 视觉下生存。

## 九、视觉下生长 (v2 池) — 未复现 (诚实负结果 ⚠️)

> 注: 本节是 **v2 架构** (全连接池) 的结果。v3 (连接掩码池) 修复后见
> 第十节, 加淘汰机制后见第十一节 — 生长验证最终在 v3+淘汰 下成立。

图像世界模型 + SparseUnit 池 (top-k 64/512), func/rand 各生长 60 个,
删 30 个 → 位置解码下降:
- func: 0.349 → 0.321 (下降 0.028)
- rand: 0.378 → 0.267 (下降 0.111)
- **func/rand = 0.25 (反向, 未复现符号实验的 1.47×)**

**原因分析**:
1. **池瓶颈 confound**: top-k 64/512 从 128 激活选 → 认知地图大幅退化
   (0.72 无池 → 0.35-0.38 有池), 生长差异被淹没在瓶颈噪声里
2. 图像模型认知地图弱 (0.35), 删除效应小且单 seed 噪声大
3. 池在图像模型的定位 (CNN→池→GRU) 可能不是最佳位置

**结论**: 图像迁移的核心 (世界模型+认知地图) ✅ 成立 (0.72);
生长机制的图像验证需要更好设置 (更松池/更多数据/多 seed), 当前未复现。
留作后续: 换池配置或换生长验证目标。

## 十、视觉 v3: 连接掩码学习 (用户架构批评驱动) ✅ 核心成功

批评: v2 池全连接无感受野, 生长不改连接 → 不是视觉神经元。
v3: 空间保留 CNN (20×20→5×5×16) + 可学习连接池
  (每神经元: score(25位置) → softmax 掩码 m → 打分 → top-k 稀疏)
  + 熵正则逼 m 尖峰 (感受野浮现)

**结果**:
- 连接熵 0.797 → 0.050: 每神经元掩码收敛到 ~1 格 = 感受野自然浮现!
- 感受野覆盖 25/25 位置 (均匀分布) — 位置调谐神经元 (V1 式)
- 认知地图: 像素 → GRU → 位置解码 0.45 (随机 ~0.05)
- 生长 (误差位置初始化): 删神经元 func/rand 差异 ±0.02 = 噪声级, 无结论 (需多 seed)

**核心结论**: 连接掩码学习 (softmax + 熵正则) 让神经元自动形成空间选择性 —
不需要预设感受野, 环境统计塑造连接 (V1 发育的计算版)。
生长删除验证需更准指标 (预测误差而非解码, 多 seed)。

**文件**: train_wm_image_v3.py, runs/wm_image_v3_func/rand.pt

## 十一、优胜劣汰生长循环 (用户洞察: 脑容量有限) ✅

问题: 之前生长只加不减 → 80% 死神经元占池。
实现: 生长(误差位置) + 淘汰(激活率<0.005 回收槽位) + 再生长 (修复 rand rng bug)

**结果 (公平对照, 同淘汰机制)**:
| 臂 | 生长存活 | 存活者激活率 | 初始神经元 |
|:---|:---|:---|:---|
| func (误差驱动) | 32 | **0.380** | 0.405 |
| rand (随机, 修复后) | 46 | 0.268 | 0.404 |

- **淘汰效果**: 生长 80 → 存活 32-46 (死神经元被回收), 存活者激活率
  从无淘汰的 0.20 → 0.38 (接近核心神经元水平) — 池保持"精选部队"
- **func > rand (激活率指标)**: 0.380 vs 0.268 (+42%) — 误差驱动生长的
  神经元参与度更高 (更接近核心神经元)
- 解码删除指标仍噪声 (探针重拟合敏感), 激活率是可靠指标

**用户洞察验证**: 脑容量有限 → 生长必须配淘汰 (优胜劣汰) →
死神经元被回收, 池容量用于真正有用的神经元。对应分支
neurogenesis + activity_pruning 的组合 (生长+用进废退闭环)。
