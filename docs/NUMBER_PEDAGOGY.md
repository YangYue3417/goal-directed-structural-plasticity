# 数字教学法汇总 (从 0 教小孩 — 完整教训链)

## 核心原则 (4 条, 每个实验验证)

```
① 概念先行: 数字需要"数量 tag" (符号 → 数量概念)
   纯符号匹配 = 不理解的查表 (最近邻 3/10, 无数值线)

② 操作教学: 算术需要"数量操作" (3+2 = tag 合并)
   符号查表 (55 对记忆) = 失败 (0.36)

③ 规则结构: 进位需要"规则" (个位循环 + 满十事件)
   模式对查表 (再多实例 0-69) = 不归纳 (泛化 0.000)

④ 自我验证: 可计算任务 = 自动奖励 (o1 式自我训练)
   生成-验证-改进可行, 但查表仍逐步慢
```

## 教学法链条 (从 0 教小孩)

```
阶段 1 数感: 数数 (顺序) + 比较 (数量) → 数量 tag 形成 (探针 1.000)
阶段 2 算术: 数量操作 (tag 加法) — 待实现 (非查表)
阶段 3 数位: 位值规则 (个位循环 + 进位事件) — 规则结构
阶段 4 泛化: 规则归纳 (进位实例) → 举一反三
阶段 5 自我: 生成-验证-改进 (计算 = 自动奖励)

= 每一步: 概念 (tag) → 操作 (数量) → 规则 (事件) → 泛化 → 自我
```

## 深层统一教训

```
"规则性任务需要规则结构, 查表监督不泛化" (4 次验证):
  数字: 数量 tag (表示结构)
  算术: 数量操作 (运算结构)
  数位: 循环/进位 (条件事件 — LIF 阈值触发!)
  自我: 自动验证 (计算正确性 = 奖励源)

= 认知结构 (tag/操作/规则/验证) 是理解的前提,
  监督查表只产生"模式匹配" (会但不懂)
```

## 与框架连接

```
LIF 阈值事件 = 条件触发 (进位 = 事件!) — 规则结构的天然机制
数量 tag = 嵌入数值方向 (线性探针可读) — 可解释
自我验证 = 可计算正确性 — o1 式自我训练信号源

= 数字教学 = 框架机制 (LIF 事件 + 可解释 tag + 自我验证) 的应用
```

## 数数能力诊断 (诚实): 路径记忆 vs 规则

- "数到 34" = 从 0 链查表 (非输出限制, 34 后错)
- **从 99 数: 失败** ([99], 不能 99→100!)
- 从 50: 失败 | 从 0: 0→36 ✅ (训练路径)

**结论**: 模型 = 0 起始路径记忆 (查表), 非数数规则
- 进位模式 (9→10 学过) 未泛化到任意起点 (99 需进位规则)
- 儿童: 规则 → 任何数能数; 模型: 查表 → 只记路径
- 需进位 = LIF 事件规则 (结构) 才能真正"会数数"

## 生长 vs 规则 (train_counting_growth.py) — 克隆≠规则

- 生长 (克隆进位样本激活神经元): 从 0 数到 19 (进步), 99 仍失败
- 删生长: 无影响 (检测器, 非规则)

**教训**: 克隆生长产生"检测器" (识别难输入), 不产生"规则触发器"
- 规则 = 结构化事件单元: 个位计数器 (V_m 累积) + 阈值事件 (满9 → 十位+1)
- 查表监督 (路径) / 克隆生长 (检测器) / 事件单元 (规则) 三者不同!

## 方案 A: 从连续量学数 (train_quantity.py) — 进位自然涌现! ✅

连续量 x → 量化 (x → round(x)) → 数字

| 验证 | 结果 |
|:---|:---|
| 量化阈值 (进位点) | 9.4→9, **9.5→10** (量变到质变!) |
| 数数 (量递增) | [0,1,...,12] 含进位 9→10 ✅ |

**突破**: 进位 = 量化阈值 (量变到质变), 非规则/查表/生长!
- 数字从量学 (量感→量化), 阈值自动学习 (自发涌现)
- 回答所有之前失败 (查表/克隆/手工规则 → 量量化 ✅)
- = "从 0 教小孩" 正确方式: 先量感 → 量化 → 数字

## 方案 A 扩展到 100 — 概念✅ 大规模需分层

| 测试 | 结果 |
|:---|:---|
| 量化精度 (0-100) | 0.620 (101 类单量化降) |
| 从 88 数 | 错乱 (大范围区间分类难) |

大规模: 单类量化难 → 需分层量化 (十位+个位组合)
= 量感 + 位值结合 (婴儿: 先量感, 再位值分位)

## 集合基数 (train_set_cardinality.py) — 数字概念输入 + 无限训练

| 测试 | 基数 | 加法(并集) |
|:---|:---:|:---:|
| 外推 ≤8/12/20 | 0.66/0.45/0.29 | 0.42/0.20/0.08 |
| **自我训练后 ≤20** | **0.58** | 0.18 |

**增加训练的方法 (有效)**:
- 无限生成 (集合组合, 基数可计算 — 数据不枯竭!)
- 自我训练 (生成→可计算验证→改进) — 基数 0.29→0.58 (2×)
- 课程 (小→大)

**诚实**: 结构操作 (并集=计数|A∪B|=|A|+|B|-|A∩B|) 仍难
- 外推暴跌 (学 ≤5 模式, 非计数结构) — 同前教训
- 数据量有帮助, 操作结构仍需针对性

## 持续训练 30 轮 (train_set_loop.py) — 涌现未达成

| 指标 | 结果 |
|:---|:---|
| 基数外推 | 停滞 0.608 (训练量饱和) |
| 加法外推 | 波动 0.26-0.36 (无涌现) |

**结论 (第 9 次)**: 更多数据不产生结构泛化
- 训练量饱和 (0.608 平台) — 数据非瓶颈
- 结构操作 (外推/并集) 需结构方法 (非数据量)
- 停止无限训练 (已证无效)
