# 框架机制总结 (发现链)

## 1. 生长触发器 (何时生长)

| 触发器 | 验证 | 判定 |
|:---|:---|:---|
| 难样本定向 (预测误差最大) | +10% (删了反而好) | ❌ 学噪声 |
| **目标驱动 (目标关键状态)** | **-14% (功能性)** | ✅ 最佳 |
| 做梦生长 (激活有方向储备) | +140% → +480% | ✅ |
| 双层 ES (频率/继承强度进化) | 弱继承 78.3 | ✅ 在线兼容 |

**结论**: 生长触发器 = 目标驱动 (目标关键状态), 非误差驱动 (学噪声)。

## 2. 生长机制 (怎么长)

- **生长→试探→连接 (baby)**: 弱初始化 (0.5W+0.3randn) + 试探期 + 巩固/淘汰 (+378%)
- **直接克隆 = 破坏** (-89%): 连接能力不能继承, 必须试探获得
- **做梦生长**: 训练塑造储备方向 (shadow 预测) → 做梦激活 (+480% 生命周期后)
- **储备生命周期**: 塑造→成熟评估→激活/保留/凋亡→再出生 (神经发生闭环)
- **双层 ES**: 进化生长策略 φ (弱继承 α=0.05 + 高频 = 在线兼容 78.3)

## 3. 连接机制

- 当前: 稀疏激活 (top-k) × 稠密连接 (全连接) × 无区域 ← 缺陷
- 记忆池 LIF: 膜电位积分 (时间感, 周期任务 48×) + τ 分工 (快/慢)
- **待实现**: 区域化 (局部连接+组内生长) + Kuramoto 耦合 (相位同步/绑定)
  → 解决非局部性冲突 (生长全局影响)

## 4. 为什么要做梦 (证据)

- **生存优先回放**: 好经验巩固 → 坏神经元被清 (删生长 +247%→+8%)
- **shadow 方向塑造**: 储备白天暗中学习, 做梦激活即用 (+140%)
- **巩固**: 片段回放 = 好结构强化 (迷宫持续存活 vs 随机)
- 生物对应: 突触稳态/慢波巩固 (巩固好 + 淘汰坏)

## 5. 如何形成固定认知能力

- **专群形成**: 目标驱动生长 → 神经元专群 (墙/食物检测器, 平衡群)
- **固定 = 专群稳定**: 区域隔离 (不被覆盖) × 做梦巩固 (强化) × 课程累积 (专群并存)
- **失败教训**: 阶段2 覆盖阶段1 (1600→117) = 无隔离 → 专群被毁
- **固定认知 = 区域隔离 × 做梦巩固 × 课程累积**

## 框架定位

- **认知为主**: 预测 (94.9%) / 记忆 (48×) / 专精 / 认知地图 (96.7%) — 全验证
- **动作 = 边界**: 神经元机制不直接做动作 (6 种方法 11-17), 需 ES 策略层
- **完整链条**: 目标驱动触发 → baby/做梦生长 → 区域专群 → 做梦巩固 → 固定能力

## 统一原则 (top1)

神经元自发涌现学习规律: 生长 = 目标驱动 (非误差), 连接 = 试探获得 (非克隆),
巩固 = 做梦 (好结构强化), 固定 = 区域专群 (隔离+巩固+累积)
