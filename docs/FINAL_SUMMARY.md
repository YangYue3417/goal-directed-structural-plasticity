# 神经元演化研究 — 完整总结与拓展方向

> 2026-08-11 | neuron-specialization 分支 | 全历程整理

## 1. 研究核心问题

**神经元能否通过"生长"适应功能? 功能集群如何涌现?**

从"类脑 MoE 专家专精"出发, 经历 5 个阶段的探索, 每个阶段都有明确结论。

## 2. 验证成果 (已证实)

### 2.1 神经元级专精 (记忆层面) ✅
- 概念相关性: 课本概念层级 → 神经元共享匹配概念依赖 (0.7-0.85)
- 神经元级 (0.855) >> 块级 MoE (0.202) — 粒度决定专精
- 视觉→神经元可解码: MNIST 98%
- 关键: 这些是**记忆分区** (模式→神经元), 非功能

### 2.2 组合泛化失败 (功能层面) ❌
- 数数/公式: 分布内 100% (记忆), 分布外 0% (无功能)
- 规模扫描 0.04M→20M (500x): 记忆↑, 功能恒零
- 结论: 功能 (组合泛化) 不是规模效应, 需要结构偏置

### 2.3 神经发生 (生长) ✅/❌
- 生长机制工作 (过量→募集)
- 生长神经元类别专精 (记忆)
- **功能 vs 随机生长无差异** → 生长只是容量机制, 无功能优势
- 因果删除验证: 删生长神经元 → 类别崩 (trivial, 同化后任何神经元都崩)

### 2.4 增量学习 (功能并存) ✅ 换结构解决
```
单网络: A(0-4)→B(5-9) 后 A 崩 (0.99→0.00) — 稳定-可塑性困境
三种结构全部解决:
  A. 渐进网络:    A=0.989 B=0.981 (新列+旧列冻结)
  B. 双专家:      A=0.991 B=0.987 (独立子网)
  D. 回放:        A=0.988 B=0.982 (持续刺激)
结论: 功能并存 = 结构策略 (分离/分工/持续使用), 非参数策略
```

## 3. 关键教训 (方法论)

1. **分类训练 → 记忆分区, 非功能** — 训练目标决定性质
2. **功能 vs 随机对照** — 排除"只是容量"的假象
3. **同化问题** — 删除验证是 trivial, 需对照随机
4. **规模 ≠ 功能** — 组合泛化需要结构偏置
5. **换结构 > 调参** — 稳定-可塑性困境的解法是架构/机制

## 5. 拓展方向 (候选)

### 方向 1: 增量学习深化 (最有基础)
- 多任务序列 (A→B→C→D), 渐进网络多列
- 结合进化: 每任务新列 + 淘汰旧列 (结构生命周期)
- 大规模增量: 任务数/数据量扩大

### 方向 2: 气味导航 (具身)
- 完成 odor_maze 训练 (多信号协调 RL)
- 位置细胞验证 (神经元空间功能)
- 结合神经发生: 新食物点 → 生长神经元?

### 方向 3: 结构进化的自动化
- 多种结构竞争 (渐进/双专家/回放), 进化选择最优
- 结构生命周期: 生长→功能→淘汰→新结构
- "器官演化"计算模型

### 方向 4: 功能涌现的规模验证
- 更大模型扫描 (100M+), 找功能涌现点
- 需要更多资源 (超出 16GB 单卡)

## 6. 建议优先级

```
P0: 方向 1 (增量学习多任务) — 基础最扎实, 可立即扩展
P1: 方向 2 (气味导航) — 具身功能, 需要 RL 稳定性
P1: 方向 3 (结构进化自动化) — 最有创新性
P2: 方向 4 (规模验证) — 资源受限

核心叙事:
  "神经元生长是容量机制; 功能并存靠结构策略 (分离/分工/持续);
   功能涌现可能需规模, 但结构偏置是关键变量"
```
