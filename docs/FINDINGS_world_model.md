# 发现: 神经世界模型 — 预测强迫空间编码 (M1-M3)

> 2026-08-12 | C 路线: 神经世界模型 | 对应 DESIGN_neural_world_model.md

## M1: 世界模型训练 (监督学习, 零 RL 方差) ✅

- 全状态枚举数据集 (20×20 迷宫, 4296 transitions, 食物过采样 20×)
- 架构: LIF (256×2, T=4) + 膜电位读出 + 线性旁路; 双头 (obs_next 回归 + reward)
- 结果:
  - 位置一步预测 MAE 0.039 (0.8 格), 墙准确率 92%, 气味 MAE 0.08
  - **奖励预测: 食物 9.75 (真实 10.05), 撞墙 -1.19 (真实 -1.0), 普通 -0.19 (真实 -0.1)**
  - 关键: 监督学习无策略梯度方差 — 之前直接策略烧 1 天的调参问题不存在

## M2: 想象规划 (MPC, 批量 BFS 展开) ⚠️ 部分

- 批量 BFS (深度 D 动作树, 每步 3 次 batched forward), 预测奖励 + 气味分数
- 结果: D=3/4/5 均 0.333 食物率 (运气 0.283, 直接策略 0.327)
- **真相**: 规划器每次都能找到近处食物 (1,0), 远处食物气味传不到
  (sigma=4 覆盖 ~5 格) → 视野内无信号 → 随机游走
- **限制**: 稀疏奖励 + 有限视野 = 与直接策略相同的探索问题
  → 需要价值函数 (Dreamer 式 critic) 或更远视野才够远处食物
  (记为后续, 非核心 — 核心是 M3)

## M3: 隐状态位置解码 (线性探针) ✅ 核心证据

枚举全部 (x,y,朝向) → LIF 隐状态 (L2 膜电位) → ridge 探针解位置:

| 来源 | 位置MAE | 1格准确率 |
|------|:---:|:---:|
| W1 世界模型 (有位置输入) | 0.0139 | **94.9%** |
| W2 世界模型 (无位置输入) | 0.1883 | 5.3% |
| D1 直接策略 | 0.2991 | 4.2% |
| 随机特征基线 | 0.5302 | 0.0% |

**P1 ✅ 成立**: 同样架构, 同样任务, 仅训练目标不同 —
  世界模型隐状态解码位置 94.9% vs 直接策略 4.2% (≈随机)。
  **预测目标强迫空间编码, 策略目标不需要** — 表征由任务需求决定。

**P2 ❌ 当前单步设置**: W2 (无位置输入) 5.3% ≈ 随机。
  信息论必然: 单步局部观测 (气味/墙/饥饿) 对位置多对一。
  自组织需要时间积分 (轨迹窗口 → LIF 递归) — 记为 M5。

## 结论 (论文可写)

1. **世界模型 vs 直接策略 = 空间表征涌现的条件对照** (94.9% vs 4.2%)
   — "预测目标"是空间编码的强迫机制, 直接策略可绕开 (与之前
   "导航不需要位置细胞" 发现完全自洽: 任务需求决定表征)
2. **LIF 精度限制**: 发放率量化伤连续回归 → 膜电位读出 + 线性旁路
3. **规划限制**: 稀疏奖励需要价值函数, 非有限视野 MPC 能及

## M5: 时间积分自组织 (W2 无位置 + 轨迹窗口) ❌ 负结果

- 架构: LIF 逐帧积分 K=8 窗口 (无位置输入) → 预测 obs_{t+K} (含位置)
- 训练: 随机游走窗口, 位置一步预测 MAE 0.063 (轨迹分布上)
- **均匀状态探针 (同 M3 协议, 反向构造 K 步历史覆盖全迷宫):**
  | 模型 | 位置MAE | 1格acc |
  |------|:---:|:---:|
  | 时间积分 K=8 | 0.2006 | 4.0% |
  | W2 单步 (M3) | 0.1883 | 5.3% |
  | 随机特征 | 0.5302 | 0.0% |
- **结论: 时间积分不恢复绝对位置** — 路径积分只给相对位移;
  气味/墙地标太局部 (sigma=4, 1 格), 无绝对锚点 → 信息论不足。
- 注意: 轨迹分布上单步 W2 探针 47.9% 是分布偏置+重复样本的假象
  (M3 均匀协议才严谨)。
- 自组织需要: 更大地标 (全局气味) 或显式起点锚或更长窗口。

## M6: 能量觅食 — 饥饿 vs 移动消耗权衡 ⚠️ 部分涌现 (模型级 ✅, episode 级部分)

问题: 闻不到远处食物时, agent 是否因饥饿压力选择觅食?

### 根因链 (三次迭代定位)
1. 预算太紧 (E0=100, cost 1) → 全员饿死, 无信号
2. 步成本进奖励 → MC 价值被"剩余步数×成本"主导, V 反了
3. **关键**: 枚举数据无死亡 transition (单步能量消耗不触发死亡)
   → 模型从没学过死亡奖励 -10 → rollout 里"饿死"不可见
   → 只看到"移动耗能" → 策略保守 (原地转)
   修复: 枚举加近空能量水平 (ef=0.001) → 死亡 transition 4287 条
   → 死亡预测 -9.6~-10.3 ✓

### 修复后: 模型级权衡涌现 (rollout 40 步, 预测累积奖励)

| 位置 | 能量 | 原地转 (保守) | 直走 (觅食) |
|------|:---:|:---:|:---:|
| 远点 (18,18) | 0.15 | -351 (死31) | -218 (死21) |
| 远点 (18,18) | 0.30 | -225 (死34) | **-10.5 (死0)** |
| 食物旁 (1,1) | 0.30 | -120 (死29) | **+1.4 (死0)** |

**模型编码了权衡**: 保守转圈 → 饿死 (死亡奖励), 觅食移动 → 续命。
能量适中时觅食大幅优于保守; 能量极低时优势缩小 (走不到食物, 死更快)。

### Episode 级 (D=3 规划 + MC 价值)
- 规划: 食物率 0.333, **饿死率 0.0** (随机 12%) → 生存达成
- 远处食物仍够不到 (D=3 视野限制, 同 M2)

### 回答用户问题
**会权衡** — 前提是模型学到"饿死"代价。当前模型级已证明:
"闻不到远处食物时, agent 在能量压力下选择移动觅食而非原地省能量"
(0.30 能量时觅食 -10.5 vs 保守 -225)。episode 级只有生存体现,
远程觅食受规划视野限制 (需价值迭代或更长视界)。

## M6b: TD 信用分配 (无枚举作弊) ✅ 生存救回

问题: 生物靠 TD 沿时间链回溯, 不靠"枚举终态"作弊。去掉作弊会怎样?

### 三臂对照
| 臂 | 配置 | 模型级 rollout (无V) | planner 饿死率 |
|:---:|:---|:---:|:---:|
| 枚举作弊 (M6) | WM 含死亡 transition | 权衡涌现 (觅食 -10.5 vs 保守 -225) | 0% |
| **TD (M6b)** | WM 无死亡 + V-TD | **反了** (保守 +1.5 vs 觅食 -16.2) | **0%** |
| 随机基线 | — | — | 14% |

### 结论
1. **半个信号问题精确复现**: 奖励头对死亡失明 → 模型级权衡反了
2. **TD 救回生存**: planner 饿死率 0% (随机 14%) — 死亡信号经 V 传播,
   不依赖枚举标注
3. **信号分工**: 即时代价 (撞墙) → 奖励头; 链终点 (死亡) → V-TD;
   长程价值 → planner bootstrap。生物式分层成立
4. 局限: TD 随机采样传播慢 (30 步链 40 passes 不收敛, V 梯度略反)
   → 顺序 TD (on-policy) 或资格迹可加速

### 意义
"完整可见的代价信号"有两层含义:
- 工程层: 显式采样终态 = 快但作弊
- 生物层: 价值函数做时间差回溯 = 慢但真实 (无需预知链条终点)
我们的实验证明了第二层可行 (生存达成), 代价是收敛慢。

## M7: 做梦实验 — 睡眠结构化重放 (train_dream.py) ✅ 机制确认

假说: 大脑睡眠 = sharp-wave ripple 按序重放 → 信用沿链完全分配。
我们 M6b 随机采样 TD 慢 = 因为不像大脑那样"做梦"。

### 表格型验证 (无函数近似干扰, 教科书式)
单条 200 步死亡轨迹, 死亡区段 (末 30 步) 价值误差:

| 方式 | 更新量 | 死亡区误差 |
|------|:---:|:---:|
| **结构化 (反向扫描=DP backup)** | **1 次扫描** | **0.0000 (完全传播)** |
| 随机 bootstrap | 8 轮 × 800 采样 = 6400 次 | 收敛 (8× 慢) |

**结论: 反向结构化重放 = 一次 ripple 全链信用分配; 随机需要 8× 更新。**

### 神经网络版 (半梯度 TD, 有干扰)
- 聚合指标被混淆: 低能量状态 = 濒死 (-10) + 食物可达 (+10) 混合,
  边际均值无信号; 死亡区段逐状态误差受函数近似干扰 (更新扰动全网络)
- 随机 TD 显著加权死亡事件 → 学到能量梯度 (-6.5); MC 回归显著性
  加权 |G|>3 同时放大食物 (+10) 与死亡 (-10) → 冲突, 学不到
- 教训: 显著性加权必须按"事件类型" (死亡/食物分开), 不能按幅值

### 与生物学的对应
```
白天在线: 经历累积 (Heaviside 强化)     = 收集轨迹
睡眠重放: 反向 ripple (reverse replay)  = 结构化扫描
  一夜 = 全轨迹信用分配 (快, 需离线)
  随机采样 = 慢传播 (可在线, 每步只回传 1 步)
```
实验支持: "做梦 = 离线快速信用分配" 的计算机制成立 (表格型严格,
神经网络型受干扰但同向)。这解释了为什么睡眠剥夺损害学习:
没有结构化重放, 长程信用只能靠慢速在线传播。

## M8: 多日昼夜循环 — 0.8x 活动 + 每晚做梦 = 三任务并存 ✅

设计 (用户想法: 活动时间 = 容量极限的 0.8x, 做梦梳理):
  Day k: 学新任务组 (0-3 / 4-6 / 7-9) 0.8×N_lim 步
  Night: 做梦 = 小 lr 重放全部历史 + 突触降标 (×0.9)
  Morning: 测所有已学任务

| 臂 | 晨1 | 晨2 | 晨3 |
|:---|:---|:---|:---|
| 做梦 | A=0.992 | A=0.978 B=0.980 | A=0.975 B=0.984 C=0.903 |
| 无梦 | A=0.981 | A=0.065 B=0.986 | A=0.000 B=0.000 C=0.916 |

**结论: 每晚重放全部历史 + 降标 → 三任务并存 (97/98/90%); 无梦 → 灾难性遗忘。**

机制:
1. 每晚重放 ALL 历史 (不只当天) — 大脑做法, 旧记忆持久
   (单夜睡眠不够: M8 前身实验中学 B 时 A 崩)
2. 突触降标 ×0.9/夜, 3 夜范数 43→37 (-14%) 不伤准确率
   — 重放补偿幅度, 保留相对结构 = 稳态恢复动态范围
3. 0.8x 活动 = 防过拟合 + 留容量

这验证了突触稳态假说的计算版本:
"白天学习消耗容量 → 夜间重放巩固 + 降标恢复 → 次日容量可用"
